~/gee/deforestation_analysis — landsat.pipeline
$ run deforestation_analysis.js --engine GEE --period 2013..2022 mission: decade-scale forest-loss mapping from Landsat archives — large-scale change detection of the kind that underpins EUDR-style monitoring. pipeline: per-year cloud-masked composites → NDVI computation → threshold-based classification of deforested area. qa: cloud masking applied before compositing — automated image-quality control baked into the workflow, not an afterthought. scale: processed server-side in Google Earth Engine, so the same script scans a decade of imagery without local downloads. $ open github.com/Subhamathi-thiruvenkatam/Deforestation_Analysis ✓
~/ml/camera_trap_challenge — vision.stack
$ python classify_and_localize.py --modes day,night mission: classify and localize animals in camera-trap imagery spanning daytime and night-vision captures. models: TensorFlow/Keras binary classifier (badger vs deer) · YOLOv5 for bounding-box localization · ResNet50 for four-class species classification. challenge: robustness to lighting variation and visually similar species — the same QA mindset used for satellite imagery, applied to sensor data on the ground. relevance: transferable to biodiversity monitoring pipelines and automated annotation workflows (CVAT/Labelbox). $ open github.com/Subhamathi-thiruvenkatam/Camera_Trap_Challenge ✓
~/thesis/peatland_soil_moisture — msc.final
$ train soil_moisture_model --imagery high-resolution --target peatlands mission: develop a machine learning model estimating soil moisture in peatlands from high-resolution imagery — critical carbon-store ecosystems where moisture governs emissions. core question: transferability — how well does a model trained on one site generalize to unseen peatland sites? A direct test of ML robustness for operational environmental monitoring. context: University of Münster, MSc Geoinformatics & Spatial Data Science. // repo: not public — findings available on request
~/thesis/rooftop_segmentation — unet.train
$ jupyter run final_year_thesis_UNET.ipynb --dataset AIRS mission: spatial governance for sustainable rooftop utilisation — semantic segmentation of building rooftops from aerial imagery. model: U-Net encoder–decoder trained on the AIRS dataset (178 train / 11 val / 18 test scenes with segmentation masks). evaluation: IoU · Dice coefficient · Matthews correlation — multi-metric validation rather than single-score reporting. output: segmented rooftop masks with bounding-box overlays on source imagery, ready for solar-potential and land-use analysis. $ open github.com/Subhamathi-thiruvenkatam/Rooftop_Segmentation ✓
